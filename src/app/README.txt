แอปทำ Lyric Video — 3 ขั้น: 1 ข้อมูล > 2 ซิงค์ > 3 ภาพรวม/ส่งออก

ใช้งานบนคอม (แนะนำ ซิงค์เร็วและแม่นที่สุด)
1) ติดตั้งครั้งเดียว:  pip install faster-whisper
   เพิ่มความแม่น (ถ้าบีตกลบเสียงร้อง): pip install demucs และมี ffmpeg ในเครื่อง
   ถ้าติดตั้ง demucs ไว้ โปรแกรมจะแยกเสียงร้องให้อัตโนมัติ ไม่ต้องกดอะไร
2) แตกไฟล์ zip แล้วดับเบิลคลิก start.bat (Windows) หรือ start.command (Mac) มันติดตั้ง faster-whisper ให้เอง (ต้องมี Python)
   รอบแรกจะดาวน์โหลดโมเดล AI ประมาณ 1.5GB ครั้งเดียว หรือสั่งเองด้วย  python start.py  เบราว์เซอร์จะเปิดแอป
3) ขั้น 1: ใส่เพลง เนื้อ นักร้อง ธีม > ขั้น 2: กดซิงค์อัตโนมัติ (ปุ่มเดียว)
   เสร็จแล้วจะเห็นผล "พร้อมใช้ x/N บรรทัด" กด "ตรวจทีละบรรทัด" เพื่อฟังและแก้เฉพาะบรรทัดที่ AI ไม่มั่นใจ
4) ขั้น 3: ดูภาพรวม > บันทึกวิดีโอ หรือดาวน์โหลดไฟล์เว็บที่ซิงค์แล้วไปแชร์/โฮสต์ได้
   (ปุ่มดาวน์โหลดไฟล์เว็บทำงานเมื่อเปิดผ่าน start.py หรือเว็บ ไม่ใช่เปิดไฟล์ตรงๆ)

ถ้าไม่รัน start.py แอปยังใช้ได้ แต่ AI จะทำในเบราว์เซอร์ ซึ่งช้ากว่าและแม่นน้อยกว่า
บนมือถือ: อัปโหลดโฟลเดอร์ขึ้น Netlify Drop / GitHub Pages / Cloudflare Pages แล้วเปิดลิงก์ใน Chrome > เพิ่มลงหน้าจอหลัก
(แนะนำซิงค์บนคอมก่อน แล้วค่อยแชร์ไฟล์ที่ซิงค์แล้ว)
